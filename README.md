# Classificação de Doenças de Pele com Deep Learning

Projeto desenvolvido na disciplina de Processamento de Imagem e Visão Computacional durante a Fase 1 da Capacitação em Inteligência Artificial do TIC 44.

## Objetivo

Desenvolver um modelo capaz de classificar doenças de pele a partir de imagens utilizando técnicas de Visão Computacional e Deep Learning.

## Tecnologias Utilizadas

* Python
* TensorFlow / Keras
* MobileNetV2
* Keras Tuner
* NumPy
* Pandas
* Matplotlib
* Scikit-learn

## Metodologia

O projeto envolveu:

* Pré-processamento de imagens com CLAHE
* Data Augmentation
* Transfer Learning com MobileNetV2
* Fine-Tuning
* Busca de hiperparâmetros com Keras Tuner
* Avaliação utilizando Accuracy, Macro F1-Score e Matriz de Confusão

## Resultados

O modelo final alcançou aproximadamente:

* Accuracy: 84%
* Macro F1-Score: 0.84
